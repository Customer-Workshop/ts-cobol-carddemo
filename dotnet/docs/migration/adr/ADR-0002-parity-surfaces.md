# ADR-0002: Parity surfaces are unloads and reports, not physical files or DISPLAYs

## Status
Accepted.

## Decision
Golden scenarios gate on (a) keyed-order sequential unloads of indexed files —
byte-exact, including records the job did not touch (missed-REWRITE detector) —
and (b) captured report/output files, line-exact. `DISPLAY` output is
diagnostic only (run.log is deleted before comparison): GnuCOBOL DISPLAY
formatting of numeric items is not dialect-stable. Physical ISAM files are
never compared. Seed data is generated by `dotnet/parity/tools/WRSEED.cbl`
(shipped seed data is degenerate); goldens are immutable — a failing .NET port
is fixed, never the golden.
